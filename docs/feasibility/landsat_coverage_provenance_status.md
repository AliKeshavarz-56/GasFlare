A spatial mosaic joins neighboring tiles within an acquisition; it is conceptually different from a temporal statistical composite. ## Test status

The full local unittest discovery run reports 48 tests: 41 passed and 7 errored. All seven errors are in the footprint-screening tests and share `ImportError: cannot import name 'Point' from 'shapely.geometry'`. The installed Shapely 2.1.2 in the existing Miniforge Python environment imports `Point` correctly, and running those seven tests alone passes. The cause is test-order module pollution: preceding tests install a stub `shapely.geometry` in `sys.modules` and do not restore it, so the footprint module receives the stub instead of the installed package. No package install, environment change, or production import workaround was made. The complete test suite cannot currently be claimed as passing; a clean full-suite run requires fixing test isolation.
